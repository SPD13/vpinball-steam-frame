        PinMAME ROM aliases

        Some tables ask PinMAME for their game under another name, often a mod ('simpprtyh' for the game 'simpprty'). Each line maps a name to a PinMAME game, as alias,game, and # starts a comment. The application adds the aliases it finds in the files of the tables (readme, script, ROM). An alias saved here applies the next time the table starts.
